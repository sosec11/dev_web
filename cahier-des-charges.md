# Cahier des charges
## Site web professionnel pour photographe

## 1. Contexte

Le projet consiste à concevoir et développer un site web
pour une photographe indépendante.

Le site doit permettre de présenter son travail et ses prestations,
d'améliorer sa visibilité en ligne et de faciliter la prise de contact
avec de potentiels clients.

Le projet a vocation à être réellement mis en production.

## 2. Objectifs

- Présenter l'univers et le travail de la photographe
- Mettre en valeur son portfolio
- Présenter ses différentes prestations
- Faciliter les demandes de renseignements et de devis
- Améliorer sa visibilité sur les moteurs de recherche
- Permettre une consultation optimale sur mobile
- Permettre à la photographe de gérer certains contenus du site

## 3. Public cible

Le site s'adresse principalement à des particuliers recherchant
un photographe pour différents types de prestations.

Exemples :
- portraits
- couples
- familles
- grossesses
- mariages
- événements

## 4. Fonctionnalités

### Visiteur

Le visiteur pourra :

- consulter le portfolio
- filtrer les photos par catégorie
- consulter les prestations
- découvrir la photographe
- envoyer une demande de contact/devis
- consulter le site sur ordinateur, tablette et mobile

### Photographe / administrateur

La photographe pourra :

- se connecter à un espace d'administration
- ajouter/modifier/supprimer une galerie
- ajouter/modifier/supprimer des photos
- gérer les prestations
- consulter les demandes reçues

### Évolutions possibles

- galeries privées pour les clients
- accès par mot de passe
- sélection des photos favorites
- téléchargement de photographies
- gestion des disponibilités

## 5. Contraintes

### Responsive design

Le site devra être utilisable sur :
- smartphone
- tablette
- ordinateur

### Performance

Une attention particulière devra être portée aux images :

- compression
- formats modernes (WebP/AVIF)
- lazy loading
- images responsives
- limitation du poids des pages

### SEO

- HTML sémantique
- métadonnées
- URLs propres
- sitemap
- robots.txt
- textes alternatifs des images
- données structurées si pertinent

### Sécurité

- HTTPS
- validation des données côté serveur
- protection du formulaire contre les abus
- protection contre les injections
- prévention XSS
- stockage sécurisé des mots de passe
- variables d'environnement pour les secrets

## 6. Hébergement

Le site sera déployé sur l'hébergement OVH de la photographe.
